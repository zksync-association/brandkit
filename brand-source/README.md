# brand-source

Primary source documents the brand kit is derived from. These are **reference artifacts**, kept in
the repo for provenance — they are intentionally **outside `skill/`**, so they are not bundled into
the redistributable skill zip (`scripts/sync.sh` zips `skill/` only).

- **`ZK-Nation-Verbal-Identity-R2-2025-10-09.pdf`** — the *ZK Nation Verbal Identity — Brand
  Positioning + Voice, R2* deck (Wednesday Studio, Oct 9 2025). The canonical source for ZK Nation's
  positioning, values, archetypes, personality, and the four voice traits. The skill carries this as
  two text references: `skill/references/verbal-identity.md` (the structured guide) and
  `skill/references/verbal-identity-source.md` (the full verbatim transcription).
