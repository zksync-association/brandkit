# Secondary Brand — ZKsync Protocol

> Source: zksync.io. Use this **only** when the user explicitly wants the **ZKsync protocol**
> brand (technical/enterprise/product) instead of the primary **ZK Nation** governance brand.

## When to use which
- **ZK Nation (primary / default):** governance, community, voting, delegation, the DAO,
  anything civic. Uses ES Allianz + Avenue Mono, the flag/ASCII visual language, salmon accent.
- **ZKsync protocol (secondary):** the technology, enterprise/institutional product surfaces,
  developer material. Cleaner, more corporate; Inter throughout.

Both share the **same color tokens and the same logomark.** Differences are below.

## Positioning & voice (protocol)
- **Tagline:** "The Bank Stack of Ethereum." Positioning: "A network of chains secured by
  cryptography, not validators."
- **Voice:** institutional, enterprise-focused, confidence-driven, declarative ("ZKsync
  connects / enables / delivers"). Real-world application over speculation.
- **Vocabulary:** cryptographically secured · ZK proofs · institutional (privacy / grade /
  readiness) · interoperability · tokenization / RWAs · settlement / finality · atomic ·
  compliance + privacy · EVM-native.

## Product names (capitalize as shown)
- **ZK Stack** — open-source framework for customizable, enterprise-grade ZK blockchains.
- **Elastic Network** — the multi-chain ecosystem (18+ chains).
- **Prividium®** — Ethereum-secured platform for institutions needing privacy + compliance + control.
- **ZKsync Connect** — interoperability protocol for institutions.
- **Airbender** — "world's fastest RISC-V prover," subsecond block proofs.

## CTAs & nav (protocol)
- Buttons: "Launch a public chain," "Launch a private chain," "Read the docs," "Contact us," "Learn more."
- Nav: Solutions · Products · Developers · Discover.
- CTA style: **triangular corner accents** on buttons (triangle bottom-left / top-right) —
  a protocol-brand signature distinct from ZK Nation's mono `▸` buttons.

## Visual style (protocol)
- More willing to use **darker, professional surfaces** than ZK Nation (still avoid full-bleed
  bright blue). Generous whitespace; hierarchical, scannable layout.
- **Typography:** Inter (sans), no Avenue Mono requirement — labels can be sentence/Title case.
- Illustration-heavy: abstract network/financial-flow diagrams; institutional partner logo grids;
  case-study cards; audit/trust badges.
- Accent geometry: **triangles** (vs. ZK Nation's flags/ASCII).

## Shared (don't diverge)
- Same color palette and tokens. Same logomark + construction/clear-space rules. Same
  "don'ts" for the mark. WCAG AA. Spell **ZKsync** correctly.
